# Dr Noushin Payravi clinic website

## Pages
- `index.html` — homepage
- `hair-loss.html` — hair loss
- `pigmentation.html` — pigmentation / melasma
- `acne.html` — acne / acne scars
- `skin-diseases.html` — common skin and scalp conditions

## Before publishing with the final domain
1. Replace `YOUR-DOMAIN` in `sitemap-template.xml`, rename it to `sitemap.xml`.
2. Add the sitemap URL to `robots.txt`.
3. Add canonical URLs and final Open Graph URLs/images.
4. Connect the domain to GitHub Pages.
5. Submit the live sitemap in Google Search Console.
6. Add the live website URL to the clinic's Google Business presence and Instagram.

The site currently uses Google Fonts for Vazirmatn.


## Final polish build
- Responsive mobile navigation added without JavaScript.
